## How to be listed

If your contribution has been merged and you are not on this list, that is our
mistake and we would like to correct it. Add yourself in the pull request that
carries your contribution, or open a pull request that adds only your row. We
list people by the name and handle they ask to be listed under; contributors who
prefer not to be named are welcome to say so.

The complete authorship record lives in the git history:

```sh
git shortlog --summary --numbered --email
```
